# Citing

If you use atrfu, please cite the thesis that describes the method:

> G. Hameed, *Rigorous Trust-Region Algorithms for Surrogate-based Grey-box
> Optimisation*, PhD thesis, University of Surrey, 2026.

To cite the software, use the metadata in `CITATION.cff`: GitHub shows it
under "Cite this repository", and each release has its own Zenodo DOI. A
journal article on the method, "Advanced trust-region funnel algorithm for
grey-box optimization", is in preparation.

The code and results that reproduce the thesis chapter are archived
separately as A-TRFu: [10.5281/zenodo.23173541](https://doi.org/10.5281/zenodo.23173541).
